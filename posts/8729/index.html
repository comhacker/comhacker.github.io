快速幂算法

发表于 2025-09-08

引入：

首先，考虑一个简单的问题：如何计算 a 的 n 次幂，即 a^n？

最直接的方法是连乘法，也就是将 a 乘以自己 n-1 次。

  • 例如，计算 2^10，我们需要进行 9 次乘法：2 * 2 = 4, 4 * 2 = 8, ..., 一直到 512 * 2 = 1024。

这种方法的时间复杂度是 **O(n)**。当指数 n 非常巨大时（例如在密码学中，n 可能是一个几百位的大数），这个计算效率会极其低下，甚至不可行。

快速幂算法就是为了解决这个问题而诞生的，它可以将时间复杂度从 O(n) 降低到 **O(log n)**，这是一个巨大的飞跃。

核心原理：

一、折半求幂

求a的n次方，如果n是偶数，那么
$$
a^{n}=a^{n/2}::a^{n/2}:=:(a^{n/2})^{2}
$$
如果n是奇数，那么
$$
a^{n}=a^{n-1}::a:=:(a^{(n-1)/2})^{2}:*:a
$$
这意味着，可以通过递归的方式来求这个值。假设要求2的10次方：

  1. 2^10 = (2^5)^2
  2. 现在需要计算 2^5（n=5是奇数）：2^5 = (2^2)^2 * 2
  3. 现在需要计算 2^2（n=2是偶数）：2^2 = (2^1)^2
  4. 现在需要计算 2^1（n=1是奇数）：2^1 = (2^0)^2 * 2
  5. 2^0 = 1（递归基/终止条件）

然后回溯：

  1. 2^1 = (1)^2 * 2 = 2
  2. 2^2 = (2)^2 = 4
  3. 2^5 = (4)^2 * 2 = 16 * 2 = 32
  4. 2^10 = (32)^2 = 1024

二、二进制求幂

任何一个数都可等价于多个2的幂相加，例如10=2^3+2^1=8+2，那么a^10 = a^(8+2) = a^8 * a^2。10的二进制形式是1010，由此可知，a^n 的值等于**n 的二进制位所有为 1 的位置所对应的 a^(2^k) 的乘积**，而每一个a的幂可以通过折半法求得。例如：

  1. 二进制数1010每一位对应的幂值分别为8、4、2、1
  2. 其中从低位到高位的第2位和第4位是1，那么求2^10可转化为求(2^8)*(2^2)
  3. 折半求幂：2^8 = (2^4)^2
  4. 2^4 = (2^2)^2
  5. 2^2 = (2^1)^2
  6. 2^1 = (2^0)*2
  7. 2^0 = 1
  8. 开始回溯：2^1 = 2, 2^2 = 4, 2^3 = 8, 2^4 = 16, 2^8 = 256。
  9. 求积 2^10 = 256 * 4 = 1024
